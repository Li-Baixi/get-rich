# Get Rich · 美股技术指标图鉴

一个 iOS 风格的单页应用(纯静态、零依赖):图文讲解 15 个常用技术指标
—— MA / EMA / SAR / BOLL / 神奇九转(TD Sequential) / MACD / DMI / RSI / KDJ / CCI / WMSR(威廉%R) / VOL / OBV / PSY / ATR ——
以及基于多指标共振的做多 / 做空 / 抄底策略、背离专题、多空计分器和 ATR 仓位止损计算器。

- 所有 K 线为程序模拟数据,图表由浏览器按真实指标公式实时计算绘制
- 手机可"添加到主屏幕"作为 App 使用(PWA,支持离线缓存)
- 支持深色 / 浅色主题、触摸十字线、键盘 ←→ 查值、每图可展开数据表
- 红涨绿跌;仅供学习,不构成投资建议
